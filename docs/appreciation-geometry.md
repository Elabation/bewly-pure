## 0. 问题定义：我们在为什么情况设计算法

低质过滤（前作）与怀旧考古（本作）在数学结构上**不是同一个问题**：

| | 低质过滤（看过，却不给） | 怀旧考古（给过，却不再被看见） |
|---|---|---|
| 目标 | 及格线：挡掉明确差的 | 发现：捞出被埋没的好 |
| 容错方向 | 宁可漏放，不可误杀 | 宁可多看候选，不可漏掉神作 |
| 判据形态 | 标量阈值（CBI<0.5） | 排序 + 多样性 + 跨年代可比 |
| 核心失配 | 推荐流偏好 vs 用户利益 | **基线年代外推 + 单标量投影丢失行为模式** |

「一套算法针对这种情况」= 解决右列三个失配。下面三个组件各对应一个。

## 1. 行为空间：一切几何的舞台

**定义（行为率向量）**：每条视频映射到 5 维向量

```
x(v) = ( coin/view, fav/view, like/view, danmaku/view, share/view )
```

在 log 空间（log(x+ε)，防零）中讨论。这个空间里的一个点，完整刻画了
「观众看完整条视频后，平均每播放产生了哪些行为」。

**前作的 F7/CBI 在这张图上是什么**：F7 是沿固定方向
w = (2.0, 3.0, 0.3, 0, 0) 的线性投影再除以 view——即**把 5 维点压扁到一条数轴上**。
CBI 是这条数轴上的位置相对基线曲线的比值。

**单标量投影丢失了什么**：方向不同的两个点可以投影出同一个标量。
互动行为有质的不同：

- **存档型**（教程/资料/合集）：fav 主导 ——「记下来以后用」
- **共鸣型**（故事/情感/人物）：coin + like 主导 ——「这值得我花钱花赞」
- **传播型**（搞笑/梗/二创）：share 主导 ——「发给别人看」
- **讨论型**（观点/解析/争议）：danmaku + reply 主导 ——「我有话要说」

硬币权重最高的 F7 天然偏爱共鸣型，对存档型与传播型神作**系统性低估**。
这不是调权能解决的——任何固定 w 都会偏爱某一种模式。要跳出「模式偏置」，
必须从「点在一条数轴上的位置」升级为「点在分布中的位置」。

## 2. AG-Depth · 多维深度判神作

**一句话**：神作不是「投影值大」，而是「行为分布的正向边缘点」。

**几何意义**：在「同播放段 × 同年代」的邻域 N(v) 内，行为点云大致呈云状
（对数正态族的常见形态）。定义 v 的**方向化分位深度**：

```
depth(v, u) = F_ν( ⟨x(v) - μ_N, u⟩ )     对投影方向 u 的分位深度
AG(v) = max_u  depth(v, u)                取所有方向中最深的
```

其中 μ_N 是邻域均值，F_ν 是该方向上投影的经验分布。u 跑遍单位球
（实践中用主方向 + 坐标轴 + 随机方向共 32 个即可覆盖）。

- 神作 = **AG ≥ 0.95**：在某个自然方向上，它是邻域里最极端的 5%
- 「正向」的甄别：极值点还需 ⟨x(v)−μ_N, u⟩ > 0 且绝对行为率不为零
  （过滤掉「反向边缘」的垃圾与「全零行为」的潜水视频）

几何图像：单一 CBI 是「离一条曲线多远」；AG 是「点云里你有多靠边」。
神作的形状不是一条线上的高位点，而是**点云边缘的凸起**——每个凸起对应一种感谢模式。

**实际意义**：
1. 捞回 F7/CBI 漏掉的三类神作（存档/传播/讨论型）——回收率是直接可测的
2. **抗单指标刷量**：刷量的视频行为向量方向不自然
   （coin 高 fav 低 like 低的「三缺一」构型在真实分布的支撑之外），
   深度判据天然压制；固定权重公式反而可被针对性刷穿
3. 与前作兼容：AG 与 CBI 双过才进「神作名录」（精确优先），单 AG 过进「候选池」（召回优先）
   ——沿用双重判定的哲学，只是从两标量变一标量+一深度

**可 falsify 的预期**：
- V1：645 条（+扩挖）中，「CBI≥1.0 但 F7 漏判」的存档/传播型视频，
  人工核对收藏证据后 AG 命中率 ≥ 60%
- V2：分歧集（AG 高 CBI 低）的规模稳定在 5-15% ——过小说明退化为 CBI，过小说明噪声
- V3：把 coins/favs 随机置换 20% 模拟刷量，AG 排名下降幅度显著大于 CBI 排名下降幅度

## 3. AG-Folium · 年代叶状基线

**一句话**：单一基线曲面 → 分年代基线叶族，让「2011 的神作」与「2026 的爆款」可比。

**几何意义**：CBI 基线是 log(view)→p50(F7) 的一条曲线，由 2020-2026 样本拟合。
跨年代使用时我们假设「感谢行为心理成本恒定」——这是报告§9 承认的最大假设。
AG-Folium 把它显式化为一族曲线：

```
baseline_y(t) = log-view → 邻域中位行为投影 的曲面，按年代 y 分叶
CBI_y(v) = proj_w(x(v)) / baseline_{y(v)}(log view(v))
```

每片「叶」由该年代的邻域数据直接估计（年份样本 n≥30 才独立成叶，
不足的年份向相邻叶插值——平滑而不硬切）。

几何图像：原来的一张曲面变成**一摞曲面**（叶状结构/foliation），
CBI 从「单一坐标系」变成「跨叶可读的公共坐标」。数据自校准取代年代外推假设。

**实际意义**：
1. 时间机器页面的排序可信度基础：不修叶，2011-2019 的名次全部悬浮
2. 「感谢低谷」现象（2021-2022 CBI 0.64-0.80）——是真时代效应还是基线失配，
   AG-Folium 落地后可以直接回答（两叶之间的系统差）
3. 每片叶自带「该年代的典型行为构成」——年代行为考古本身就是一个发现
   （例：2019 年的 coin/view 中位数 vs 2026 年，直接量化「感谢习惯的迁移」）

**可 falsify 的预期**：
- V4：叶状基线 vs 单一基线，在 2019-2022 段产生 ≥ 8% 的 Top-20 排名翻转，
  且翻转方向与「该年代行为构成差」一致（人工核对 10 例）
- V5：叶内拟合残差 ≤ 单一基线残差的 90%（对数空间 MSE）

**依赖**：每年代 n≥30。当前 2019(n=84)/2025/2026 够，2011-2018 靠扩挖 + 插值。

## 4. AG-Compass · 方向引导挖矿

**一句话**：收藏夹 = 行为空间里的一个方向（品味锥），挖矿 = 沿已验证的高值方向扩展。

**几何意义**：一个夹的成员行为向量取几何中位数方向，得到**品味向量** u_c。
夹质量 = 成员 AG 深度均值。两个夹的相似度 = u_c 夹角。
于是「挖矿」从盲目抽样变成**锥上的波束搜索**：

```
1. 已验证夹集合 C（AG 均值 ≥ 0.9）→ 品味锥 K = cone{u_c}
2. 新用户抽样时，优先采其夹与 K 的最大夹角小的（方向先验）
3. 每轮挖掘后更新锥 K（指数滑动，防漂移）
4. 多样性约束：桶（方向簇）内轮转采样，保证锥不被单一品味垄断
```

几何图像：在行为空间里，高价值区域不是一个个点，而是**若干窄锥**；
挖矿预算应该沿锥轴推进，而不是在整个空间撒网。

**实际意义**：
1. **请求预算效率**：第一轮神作率 36.4%。方向引导的预期 ≥ 55%
   （同样 1000 个请求，挖到的神作数量 +50%）——API 是瓶颈时这是直接翻倍
2. 「怀旧频道」的产品化：品味锥天然给出频道划分（存档频道/共鸣频道/传播频道…），
   每个锥轴一个策展流——多样性由锥间轮转保证
3. 冷启动友好：锥 K 从前作报告的高分视频初始化，不依赖挖掘数据量

**可 falsify 的预期**：
- V6：留出法离线模拟——50% 夹做种子建锥，另一半做靶；
  方向引导 Top-k 的神作命中率 ≥ 随机挖掘的 1.4 倍
- V7：锥数收敛到 4-8 个（行为模式有限论），且各锥的「命名一致性」人工评审通过

## 4.5 AG-Flow · 用户-神作流（Elabation 提出，本框架的图论引擎）

> 原始直觉（2026-09-02）：「找到高分作品 → 去高分评论区筛用户 → 看收藏 →
> 找到高分作品……像一股流一样流过去。树会越跑越大崩溃，
> 所以流到哪里流不动了就大胆剪枝。」

**精确化**：这是**用户×作品二部图上的交替得分传播**——与 HITS（hub-authority）
和带重启随机游走（RWR）同族，但边上有 ours 特有的几何权：

```
二部图 G：节点 = 用户 u 与视频 v；边 = u 收藏过 v（或 u 评论过 v，权重低）
边权 w(u→v) = AG-depth(v) 的单调函数（行为质量已判定的边才进入传播）
迭代：
  S(u) ← Σ_{v∈N(u)} w(v) · sim(u_c, K)      用户得分 = 其收藏的加权质量 + 品味锥契合
  S(v) ← Σ_{u∈N(v)} S(u) · w(u→v)            作品得分 = 收藏者质量的汇聚
  （交替迭代至能量收敛 = 「流」的稳态）
剪枝（Ricci collapse 类比）：
  分支神作产出率 < 全库基线 × α（α=0.5）连续 m 步 → 整枝剪掉
  = 低传输价值边不进入下一轮扩散（曲率坍缩）
```

**与 AG-Compass 的关系**：Compass 在行为向量空间定方向（冷启动可用）；
Flow 在图结构上传能量（图长起来后更强）。生产形态：Compass 出候选、
Flow 定优先级——两者是同一台挖矿引擎的两个视角，不是二选一。

**实际意义**：评论区是全网最大的「高参与度用户」公开名单——
高分作品评论区尤其如此（愿意给神作留言的人，收藏夹里有货的先验概率更高）。
流把这个先验变成可执行的采样策略，比「uploader 种子」和「随机 UID」都更贴目标。

**两个待证命题（用户明确要求控制变量+统计学）——2026-09-02 判定揭晓：**

- **E1 同配性（流的前提）——✅ 通过，强显著**：
  神作（CBI≥3.0）评论区用户的收藏夹神作率 **25.9%**（n=36 用户）vs uploader 基线 **5.9%**（n=20），
  **ratio = 4.40×，MWU z=4.57，p=2.5e-06**——远超 1.3× 线。
  「在高分作品评论区留言的人，收藏夹里有货」——前提成立，且强度超预期。
- **E2 流的净效果（排除混杂）——✅ 通过**：
  臂① **25.9%** vs 臂③普通视频评论区用户 **18.2%**（n=34），**ratio = 1.42×，p=0.025**。
  臂③对照的必要性被证实：臂③也显著高于 uploader 基线（z=3.60, p=0.00016）——
  「评论行为本身」确实是筛选器（混杂真实存在），但扣除它之后，**流的高分定向仍有 42% 净增益**。
- 结论：**AG-Flow 成立**。结构：评论区是高参与度用户名单（普遍 +13 个百分点），
  高分作品评论区是其中更准的子集（再 +8 个百分点）。流的收益 = 两层筛选的乘积。
- **E3 剪枝曲线（第二+三跳，2026-09-02 完成）——✅ 零衰减且反增，「深流可行」成立**：
  三点曲线（用户级神作率，基线 5.9%）：
  **第一跳 25.9%（4.40×，p=2.5e-06）→ 第二跳 24.5%（~4.2×）→ 第三跳 32.8%（5.57×，p=2.25e-07）**。
  优秀率同步走高（43.8%→39.3%→50.7%）；每请求神作产量逐跳上升（0.112→0.183→0.216）。
  **机制归因（诚实）**：第三跳反增的主因是种子池构成变化——汇流门槛在稀疏采样下凑不满种子，
  以「CBI top 补足」引入超神种子（实测种子池含 CBI 15.7/14.1/10.2 的存量神作，最高为库均值的 15.7 倍），
  种子质量上升 → 其评论区的分层信号更强。即「掺水」实际是「浓缩」：补足机制不稀释信号反而提升种子纯度。
  **预算-产出拐点**：每跳内部仍有清晰的边际递减（第二跳前 1/3 预算 38.7% → 全量 24.5%）——
  跳内剪枝有效；**跳间无衰减**——流的深度受种子池规模约束而非信号衰减约束。
  α 截断效率（跳内）：第二跳 0.288→0.226→0.197 递减；第三跳在候选池扩大后平坦（0.185→0.220）。
- **实操准则（定型）**：停流 = min( 边际神作率 < 1.3×库基线 ,  ρᵏ < 0.5 ,  种子池 < 10 )。
  实测衰减率 ρ≈0.95-1.2（不衰减甚至反增）——统计准则远未触发，**流的实际深度由种子池枯竭决定**；
  「CBI top 补足」是维持种子池的合法手段（浓缩而非稀释）。等预算下多条并行短流优于单条深流
  （第一跳增益恒最大），流是广度优先的分形灌溉。
- **诚实备注**：① 汇流度≥2 的神作在 95 用户规模下仅 4 个——汇流度信号（流强度分层）在当前采样密度下
  无区分度，其作为剪枝信号的有效性待更大种子规模检验；② 第二跳的「无衰减」与第三跳的「反增」
  均伴随种子池构成变化，属于描述性结论；但对基线的 4.4-5.6× 差距在任何口径下都远超抽样噪声。

**几何×统计交叉解释**（组合拳的落点）：
- Flow 的稳态能量分布 = 行为空间品味锥上的测度集中——统计命中率是几何集中度的投影
- 剪枝曲线的拐点 = 图上「品味簇」的边界——簇内高传输、簇间低传输
- E1 的 Spearman ρ 就是「评论行为与收藏品味」在两个空间里的耦合强度

### 4.6 AG-Flow 二部图模型（E1/E3 的统一数据结构）

AG-Flow 的全部实验共用一张数据结构，分四层抽象：

**存储层**：`favmine_<时间戳>.json` 两张扁平表——`users`（挖掘台账）+ `videos`（流水），
每条视频携带 `from_user` 字段。磁盘上无嵌套、无图；原始文件 immutable（数据纪律 §〇）。

**逻辑层**：`from_user` 把两表缝成**用户-视频二部图**：
- 左部 = 用户节点，右部 = 视频节点，边 (u,v) ⇔ 「u 的公开收藏夹含 v」
- 简单图（bvid 去重，同边只存一次），边只跨部、部内无边
- 两个天然统计量：**出度**（用户收藏的合格视频数 = 该用户的样本量）与
  **入度**（视频被多少用户收藏 = 该视频的「汇流度」）

**生成层**：图 = 「从种子出发的两跳遍历」快照——
种子视频池（图外，CBI≥3.0 过滤器）→ 第一跳热评接口（产生左部）→ 第二跳收藏夹接口（产生右部+边）。
三臂同构，唯一种子过滤器不同（神作评论区 / uploader / 普通视频评论区）——控制变量在实现层兑现。

**统计层**：E1/E2 指标全部定义在图上——
用户神作率 = 左部节点出边的右部 tier=high 比例（局部函数）；臂级均值 = 左部合格节点（出度≥5）均值。
四指标 × 三臂 × 三对照的 12 组 MWU 全显著（见 §4.5），且**尾部指标（神作率 1.42×）强于均值指标（CBI 1.20×）**
——流的增益集中在「撞见神作的概率」，不在平均收藏水平：挖矿找宝藏，不买指数。

**树状遍历与图遍历的分野（E3 的理论前提）**：树不允许入度>1，会把「多条独立路径指向同一视频」
的汇流事件结构性抹除；二部图保留它——**汇流度本身即无监督置信度加权**（多源同指 = 强信号）。
E3 剪枝因此是图上按流量剪边，不是树上剪分支。

**报告交付物（W7）**：① 本章作为报告「F7 几何」章的模型节展开；
② **流动画**：SVG/JS 动画呈现流的真实路径——神作种子 → 评论区用户节点亮起 → 沿收藏边扩散 →
汇流节点增亮（入度映射光强）→ α 剪枝时稀疏边熄灭——数据用真实臂①/E3 图，不做示意。

## 5. 三件套的关系与数据流

```
              挖掘（AG-Compass 引导）          AG-Folium 校准
   B站公开API ──────────────────→ 原始stat ─────────────→ 基线叶族
        ↑                            │                        │
        │ 锥K反馈                     ↓                        ↓
   用户/夹候选池               行为向量 x(v)              AG-Depth 判定
                                     │                        │
                                     └────→ 神作名录 + 候选池 + 年代行为档案
                                                  ↓
                                        时间机器（待验收后开发）
```

- Compass 决定**去哪挖**（预算效率）
- Folium 决定**怎么比**（跨年代公平）
- Depth 决定**算什么**（发现目标）

三件套全部只依赖公开 API 元数据，法律等级与现有管线一致。

## 7. 诚实边界

1. AG 的「正向边缘」判据依赖邻域纯净度——若邻域本身被刷量污染，深度会被拉偏。
   缓解：邻域仅取 view≥3000 且三指标非零的点；未来可加“行为构成合理性”先验。
2. 叶状基线在 n<30 的年代是插值产物，报告里必须标灰，不得参与趋势结论。
3. 品味锥的「命名」（存档/共鸣/传播…）是人给的标签，算法只保证锥的分离性；
   语义解读属于人，不属于数据。
4. 本框架**不**承诺比 CBI「更准」——它解决的是 CBI 结构上无法解决的问题
   （模式偏置/年代失配/预算效率），三者相互独立、可分别证伪。
