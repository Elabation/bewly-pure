# 洁净B站 · 安装与使用教程

> 三分钟装好，夺回你的首页。
> 报告（为什么这么做）：https://elabation.github.io/clean-bilibili-report/web/ecosystem-report.html
>
> 本插件不登录、不上传、不碰你的账号数据——所有判定在你的浏览器里完成，只调用 B 站公开接口读取视频的公开互动数。

---

## 一、它能做什么

打开 B 站首页时，插件自动做两件事：

1. **同步层（响应即删）**：直播、时长 ≤75 秒的短视频、标题命中「第N集/话」「挑战体」切片签名的卡片，直接从响应里删掉——根本不渲染；
2. **异步层（感谢指数判定）**：对留下的每个视频调 B 站公开接口，读取 收藏/投币/点赞，计算 **CBI 感谢指数**（= 加权感谢率 ÷ 同播放段基线），把「播放量很大、观众却几乎不给硬币收藏」的**「看过，却不给」**卡片隐藏，其余卡片右上角打上透明度评分角标。

全部阈值可手调（见第四节）。

## 二、安装（3 分钟）

### 第 0 步：装 Tampermonkey

| 浏览器 | 安装地址 |
|---|---|
| Chrome / Edge | https://www.tampermonkey.net/ （或各自扩展商店搜 Tampermonkey） |
| Firefox | https://addons.mozilla.org/firefox/addon/tampermonkey/ |

装好后浏览器右上角会出现黑底方块图标。

### 第 1 步：装脚本（二选一）

**方式 A · 一键安装（推荐）**

Tampermonkey 保持启用状态，点击这个链接，Tampermonkey 会自动弹出安装页：

> https://github.com/Elabation/clean-bilibili-report/raw/main/userscript/bilibili-clean.user.js

在弹出的页面里点绿色按钮「安装」即可。

**方式 B · 手动粘贴**

1. 打开 https://github.com/Elabation/clean-bilibili-report/blob/main/userscript/bilibili-clean.user.js
2. 点右上角「Raw」（或「复制」按钮）拿到全文
3. 浏览器右上角 Tampermonkey 图标 → 「添加新脚本」→ 全选删除模板 → 粘贴全文 → `Ctrl+S` 保存

### 第 2 步：验证生效

打开 https://www.bilibili.com （脚本只作用于首页推荐流）：

- **左下角**出现「洁净B站 已过滤 N」的常驻小角标（点开各原因计数）；
- 每张留下的卡片**右上角**出现评分角标：`CBI 1.32 · 知识`（CBI＝感谢指数，≥1 为达到同类平均感谢水平）或 `F7 0.081`（播放量不足 5 万时显示原始感谢率）；
- 按 `F12` 打开控制台，输入 `CleanBili.counts` 可看实时分类统计。

看不到角标？见第五节 FAQ。

## 三、判定逻辑一览（对应调查报告 §13）

```
同步层（响应即删，卡片根本不渲染）
  直播            R1
  时长 ≤ 75s      R1        ← 短视频硬偏好
  第N集/话·挑战体  R7        ← 仅采用经过 6,734 条样本检验的标题签名（p<0.01）

异步层（view API 补全收藏/投币后）
  竖屏            R1 → 隐藏
  播放 < 1000     R1 → 隐藏（新稿保护线）
  官方区白名单     R4 → 电影/电视剧/纪录片 跳过 CBI（它们感谢率天然垫底，§7）
  播放 ≥ 5万 且 CBI < 0.5   R2 → 隐藏「看过不给」
  播放 3千~5万     R2'→ 全局兜底，只隐藏最低档 junk（low 只打标）
  「投币X更新」    R8 → 角标打「乞」标，只提醒不惩罚
```

公式（报告 §1/§6）：

```
F7  加权感谢率 = (3×收藏 + 2×投币 + 0.3×点赞) / 播放
CBI 感谢指数   = F7 ÷ 同播放段基线中位数（6,734 条样本滑窗拟合，脚本已内置曲线）
```

设计纪律：**不用 log 分母**（会把质量分变成热度探测器，§9）；**不做标题文体歧视**（emoji/感叹号/排版与感谢率无稳定关系甚至反向，§14）。

## 四、手调参数

脚本头部 `CONFIG` 就是参数表（与仓库 `config/clean.config.json` 同构）。Tampermonkey 图标 → 管理面板 → 点脚本名进入编辑 → 改完 `Ctrl+S` → 刷新 B 站生效。

| 想改什么 | 位置 | 默认 | 说明 |
|---|---|---|---|
| 短视频判定线 | `filters.short_video_max_duration_sec` | 75 | 秒；改成 0 关闭 |
| 竖屏过滤 | `filters.portrait.enabled` | true | 竖屏内容是否隐藏 |
| 播放保护线 | `filters.min_views` | 1000 | 低于此播放量直接隐藏 |
| **CBI 判定线** | `cbi.threshold` | 0.5 | 调大（0.6）更严，调小（0.4）更宽容 |
| CBI 起判播放 | `cbi.min_view` | 50000 | 播放低于此值不做 CBI 判定 |
| 白名单分区 | `filters.zone_whitelist` | 电影/电视剧/纪录片 | 加入「影视」等可豁免更多官方区 |
| 标题黑名单 | `filters.block_keywords` | 两条正则 | 正则数组，命中即隐藏；**别加 emoji/感叹号**（无效甚至反向，§14） |
| 乞讨文本 | `filters.beggar_patterns` | 投币/三连/点赞 | 只打标；想隐藏就把该卡片逻辑改掉 |
| 角标显示 | `ui.show_badge` / `ui.show_counter` | true | 嫌挡眼可关 |

## 五、FAQ

**Q：装了没反应？**
按顺序检查：① Tampermonkey 面板里脚本是否处于启用状态（图标不灰）；② 当前页面是否 `www.bilibili.com` 首页（视频播放页/空间页不处理）；③ 刷新一次首页；④ F12 控制台看有没有红色 `[CleanBili] hook error`——有的话带着截图提 issue。

**Q：把我喜欢的内容也藏了？**
两种解法：① 角标会告诉你原因（如 `CBI 0.42`）——如果你觉得它被冤枉，把 `cbi.threshold` 调到 0.4 试试；② 内容属于官方区（如影视解说被划进电影区），把它加进 `zone_whitelist`。过滤哲学是「宁可放过，不可冤枉」——所有判定都可关。

**Q：会封号 / 有风险吗？**
脚本只读取 B 站公开的 view 接口（浏览器正常访问也会发的请求），不写入任何数据、不模拟登录、不碰风控接口。理论上与你手动打开视频页看数据无异。但请自担使用风险，本项目与 B 站官方无关。

**Q：为什么左下角统计和我感觉不符？**
「其他」计数包含广告卡与非视频卡（它们本来也不该出现在推荐流）；部分「看过不给」的卡片是 B 站预加载但尚未滚动到的，滚到时才被隐藏——统计先行于视觉。

**Q：手机端能用吗？**
安卓可通过支持扩展的浏览器（如 Firefox + Tampermonkey、Edge Canary + 扩展）加载同一脚本；完整免 root 方案评估见 `docs/mobile-plan.md`。

**Q：数据 / 结论可信吗？**
见调查报告：7,537 条视频、2019-2026 八年跨度（「每周必看」387 期）、十三项统计实验（偏相关、分位回归、洛伦兹/基尼、PCA、χ²、MWU 检验等），以及它们的局限说明。报告在线阅读：https://elabation.github.io/clean-bilibili-report/web/ecosystem-report.html
