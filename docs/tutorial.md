# 洁净B站 · 安装与使用教程

> 两分钟装好，夺回你的首页。
> 调研报告（为什么这么做）：https://elabation.github.io/bewly-pure/web/ecosystem-report.html
>
> 本插件不登录、不上传、不碰你的账号数据——所有判定在你的浏览器里完成，只调用 B 站公开接口读取视频的公开互动数。

---

## 一、它能做什么（PC 端 · Edge/Chrome 扩展）

基于 [BewlyBewly](https://github.com/hakadao/BewlyBewly)（MIT）的增量版：BewlyBewly 的成熟首页网格框架 + 我们的 **CBI×F7 双重低质过滤**。

装好后打开 bilibili.com，首页变为 BewlyBewly 网格铺平模式，同时：

1. **同步层（拉流即滤）**：直播、短视频（时长可调）、标题命中切片签名的卡片，直接不渲染；
2. **CBI×F7 双重判定**：自动查视频的 收藏/投币/点赞，计算
   - **F7 加权感谢率** = (3×收藏 + 2×投币 + 0.3×点赞) / 播放
   - **CBI 感谢指数** = F7 ÷ 同播放段基线中位数（6,734 条真实样本拟合，内置曲线）
   - **双重判定**：CBI 与 F7 都低于线才砍（单指标弱不冤枉，宁放过不冤枉）；
3. **评分角标**：每张卡左下角实时显示 `CBI 1.32 · F7 0.18`（颜色分档：优 / 弱 / 低质 / 未判定）；
4. **状态胶囊**（左下角）：实时过滤比率（如「已过滤 32%（已检 673 张）」）、判定缓存命中、接口健康；任何异常自动熔断并红点提示，可一键解除；
5. **四档性能**：并行（默认，快筛免请求+无跳脸）/ 闪滑（判定限时 800ms，极快）/ 标准（每批全量判定，最稳）/ 极速（零请求只标不砍）；
6. **判定缓存**：判定过的视频存本地，重复推荐不再发请求，越用越快。

手机端**尚未完成**（方案在评估，见仓库 docs/mobile-plan.md）。

## 二、安装（2 分钟）

1. 打开仓库 https://github.com/Elabation/bewly-pure → 绿色 **Code** 按钮 → **Download ZIP** → 解压
2. 进入解压出的文件夹，找到 **`extension-bewly.zip`**，把它也解压（得到一个含 `manifest.json` 的文件夹）
3. Edge 地址栏输入 `edge://extensions` 回车（Chrome 为 `chrome://extensions`）
4. 打开「**开发人员模式**」开关
5. 点「**加载解压缩的扩展**」→ 选中上一步解压出的 `extension-bewly` 文件夹
6. 打开 https://www.bilibili.com ——首页已是 BewlyBewly 网格 + 洁净B站过滤

> 也可以只下载仓库里的 `extension-bewly.zip`（不下载整个仓库），解压后从第 3 步开始。

## 三、验证生效与日常使用

- 首页变为网格铺平，卡片左下角出现评分角标 `CBI x.xx · F7 x.xx`
- 左下角有「洁净B站 · 并行」状态胶囊，点开看实时过滤比率、砍卡明细、接口状态
- **所有参数手调**：BewlyBewly 设置（左侧 Dock 齿轮）→ 通用设置 → 「洁净B站 · CBI 过滤」分组：
  - 总开关 / 性能模式 / 双重判定开关
  - **F7 线**（默认 0.04；想要地狱模式可调 0.1——全站只有约 20% 视频达标）
  - CBI 判定线（0.5）/ CBI 起判播放量（5 万）/ 短视频秒数（75）/ 播放保护线（1000）/ 官方区白名单
- 参数改动在下次刷新后生效（判定过的卡片按当次设置）

## 四、FAQ

**Q：装了没反应？**
① `edge://extensions` 确认扩展已启用；② 确认在 `www.bilibili.com` 首页；③ 刷新一次；④ F12 控制台看有没有红色 `[洁净B站]` 报错——有的话带截图提 issue。

**Q：看到低分卡漏进来？**
双判定设计是「宁放过不冤枉」：F7 达标的卡即使 CBI 低也不砍。想更严：调高 F7 线（如 0.06-0.1）或关闭双重判定（设置里）。另外左下角胶囊如果变**黄**（接口限流退避中）会临时只做轻量过滤，几分钟后自动恢复。

**Q：角标显示「未判定」？**
判定接口临时被限流，进入退避保护（黄点），恢复后自动继续。

**Q：会封号 / 有风险吗？**
扩展只读取 B 站公开的 view 接口（浏览器正常访问也会发的请求），不写入任何数据、不模拟登录。判定结果本地缓存，不会重复请求。使用风险自担，本项目与 B 站官方无关。

**Q：手机端能用吗？**
还没做——免 root 方案在评估中（docs/mobile-plan.md），完成会在仓库公布。

**Q：数据 / 结论可信吗？**
见调研报告：7,537 条视频、2019-2026 八年跨度、十三项统计实验及局限说明。在线阅读：https://elabation.github.io/bewly-pure/web/ecosystem-report.html
