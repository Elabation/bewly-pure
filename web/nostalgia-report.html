SECTION 01 · 一枚硬币的两面

过滤是防守，考古是进攻

前一份报告的结论浓缩成一句话：B 站的推荐流把大量「播放量巨大、感谢稀薄」的视频塞给你，我们把它们过滤掉。那是防守——守住你的首页。

但过滤只能挡住坏的东西，它不会把好的东西送回来。B 站的时间线是单向的：一个 2015 年被投出十万硬币的神作，和昨天发布的低创视频相比，在今天的推荐流里几乎是同等不存在的。算法只认识「新」和「热」，不认识「好」。

有一个地方例外——收藏夹。收藏是观众用行为投票留下的策展记录：一个人把什么视频郑重地放进「我的收藏」，往往比他点过多少赞更能说明这个视频值得被记住。每一个公开收藏夹，都是一个普通人为互联网做的迷你博物馆。它们加起来，就是一条被时间线单向性掩埋的平行时间线。

本次调查的问题：如果我们把这条平行时间线挖出来、用同一把 CBI 的尺子丈量，①它里面「神作级内容」（CBI ≥ 1.2）的比例有多高？②它能覆盖多早的年代？③收藏夹本身是不是一种可靠的「质量签名」？
SECTION 02 · 尺子：同一把，不多不少

F7 与 CBI：从前作全文照搬

为了保证与前作可比，本报告不发明任何新指标，公式与基线曲线逐字段同源于《看过，却不给》与扩展 core.ts：

F7 = (3.0×收藏 + 2.0×投币 + 0.3×点赞) ÷ 播放
CBI = F7 ÷ baseline(log₁₀ 播放) —— 基线：n=6734 条样本拟合的 28 点中位数曲线（2026-09 拟合，与扩展内置曲线完全一致）

CBI 的语义：1.0 = 与同播放段的典型视频感谢水平持平；≥ 1.2（超出基线两成）我们称为神作线；≥ 1.0 称为优秀线；< 0.5 为「看过不给」区。分级线与前作一致，保证两张报告的数字可以直接对读。

为什么坚持「相对基线」而不是绝对阈值：不同播放量段的感谢率天然不同（万播视频与千万播视频的感谢率可以差 3 倍），只有除以基线，2013 年的神作和 2026 年的爆款才能放在同一把尺子上。

SECTION 03 · 挖掘方法学

如何诚实地挖一座矿

隐私声明（先于一切结论）：本调查只访问 B 站公开接口与公开收藏夹（私有夹在接口层即不可见，属性位逐夹校验）；用户身份在入库瞬间做 SHA-1 短哈希匿名化，报告与数据集只出现视频、永不出现人——不排名、不点名、不构建任何用户画像。全程仅 API 元数据，无登录态、无写入。

挖掘管线四步

① 种子用户：从前作样本库随机抽取视频，反查其 uploader 作为种子——uploader 是重度 B 站使用者，收藏夹的「策展性」强。② 夹筛选：对每个用户拉取其创建的收藏夹列表，只保留公开（attr 私有位=0）且条目数 > 3 的夹，每用户最多挖 3 个；无自建公开夹的用户回退考察其收藏的他人公开夹。③ 条目抽取：每夹取最近收藏的 20 条（收藏夹接口自带发布时间/播放/收藏数），对其中约 80% 补查 view 详情获取投币与点赞。④ 打分入库：F7/CBI 按前作公式计算，与基线比对定级。

对照组

对照数据来自前作的采集流（排行榜 / 热门 / 推荐流，2026-09 采集，n 见下节），用完全相同的公式与基线重新打分。它代表「今天的时间线愿意主动给你看的东西」的质量水位——这正是我们要超越的基准线。

SECTION 07 · 收藏夹是质量签名吗

夹与夹之间的方差，比夹内大得多

如果「收藏行为」普遍代表质量，那么任意两个收藏夹的质量分布应该相近。数据给出的答案更有趣：夹与夹之间差异巨大——有的夹优秀率超过九成，有的夹不足两成。收藏不是质量的名片，策展人的品味才是。

产品含义：这正说明「按用户排名」是错误的产品形态，而「按视频入库」是对的——我们要吸收的是好夹里的好视频，而不是给任何用户贴标签。全体用户在报告中一律匿名。

SECTION 09 · 方法学与局限

这份报告不能告诉你什么

① 选择偏差（最重要）：种子来自 uploader（重度用户），且回退夹多为「收藏的他人公开夹」——挖掘组天然偏向「策展活跃者」的视野，它不能代表全体 B 站用户的收藏水位。② 对照组口径差：对照组是排行榜/热门/推荐流的当期样本（幸存者偏差极强——它们是已经赢了曝光竞赛的视频），挖掘组是个体收藏（无曝光竞赛）。两者的对比回答的是「平行时间线 vs 曝光竞赛」的水位差，不回答「收藏是否比随机推荐好」。③ 样本量：第一轮 n 见 KPI，部分年份条目极少（n<5 不进入趋势推断）。④ CBI 曲线的年代外推：基线由 2020-2026 样本拟合，用于 2013-2019 年视频时假设「感谢行为的心理成本跨年代稳定」——这是本报告最大的假设，无法自证。⑤ 每夹截取最近 20 条：收藏时间接近，近似「同一时期的一次策展」，不代表夹主全部历史。

上述局限没有一条可以轻率略过。这份报告的价值在于建立了管线与可复核的口径，让后续每一轮扩挖都能在同一把尺子上累加证据。
