# Edge 扩展版 · 安装说明（自研扩展，无需 Tampermonkey）

这是洁净B站的独立浏览器扩展（Manifest V3），**不需要任何脚本管理器**。
它直接接管 bilibili.com 首页推荐流：网格铺平渲染，CBI 感谢指数判定，低质卡片根本不渲染。

## 安装（Edge，2 分钟）

1. 下载本仓库（Code → Download ZIP，或 git clone），得到 `extension/` 文件夹
2. Edge 地址栏输入 `edge://extensions` 回车
3. 打开左下角「**开发人员模式**」开关
4. 点顶部「**加载解压缩的扩展**」，选中本项目的 `extension/` 文件夹
5. 打开 https://www.bilibili.com ——完成

首次使用建议点一下扩展图标里的「重新加载」确认版本。Chrome 同理（`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序）。

## 它做了什么 / 没做什么

| | |
|---|---|
| 接管范围 | 仅 bilibili.com 首页推荐流（网格铺平 + 无限滚动） |
| 保留功能 | B 站原顶栏原样保留：搜索、头像、历史、收藏、消息全部原生可用 |
| 判定规则 | 与 userscript / 报告 §13 完全一致（R1-R8，CBI<0.5 看过不给） |
| 数据来源 | 自建 wbi 签名直连 B 站公开接口（rcmd 推荐 + view 详情），**不劫持页面请求** |
| 低质卡片 | **不渲染**（网格自动重排，无空洞无占位条） |
| 切回原版 | 状态条右上「切回原版」一键还原（本次会话内） |
| 隐私 | 全部本地计算，无任何上报 |

## 文件结构

```
extension/
  manifest.json   扩展清单（MV3，content_scripts 匹配首页）
  md5.js          MD5 实现（wbi 签名依赖）
  content.js      核心：wbi 签名 → 拉推荐流 → 同步过滤 → 网格渲染 → 懒判定
  content.css     网格布局样式（亮/暗双主题）
```

## 与 userscript 版的关系

| | userscript v0.3 | Edge 扩展 v1.0 |
|---|---|---|
| 依赖 | 需要 Tampermonkey | 无依赖 |
| 方式 | 拦截页面请求，在原版页面上过滤 | 自建推荐流，网格重绘整个首页 |
| 低质卡片 | 隐藏 + 占位薄条 | 根本不渲染 |
| 适合 | 想保留 B 站原版界面 | 想要干净的网格体验 |

判定核心同源（同一套曲线与阈值），两者可共存（扩展的接管优先）。

## 更新
